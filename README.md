# Open Hearts Club Website Preview v0.1.2 - Flat GitHub Upload Edition

This release intentionally places all website files in the repository root.

Why: GitHub's web upload interface can be awkward when uploading files into
nested folders. This version removes that source of error.

Upload every file in this folder to the ROOT of the OpenHeartsClub-Website repository.

Required root files include:
- index.html
- 404.html
- styles.css
- site.js
- open-hearts-club-logo.png
- CNAME
- .nojekyll
- all page .html files

GitHub Pages source should be:
- Branch: main
- Folder: /(root)
